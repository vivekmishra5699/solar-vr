# 🌌 Solar VR - Explore the Cosmos in Virtual Reality 🚀

![Solar VR](https://user-images.githubusercontent.com/vivekmishra5699/solar-vr-banner.png)

### 🪐 **A Realistic & Interactive Solar System Simulation in VR**
**Solar VR** is an immersive **Three.js & WebXR**-powered experience that lets you explore the **solar system** in **virtual reality**. Witness planets orbit, experience real-time physics, and interact with celestial bodies like never before! 🌠

---

## 🌍 **Features**
- 🔭 **Fully Interactive Solar System** – Walk around planets, zoom in on celestial bodies, and explore their details.
- 🏗 **Realistic Scaling & Orbits** – True-to-scale planetary sizes and orbital mechanics.
- 🕶 **VR & Non-VR Support** – Works with **VR headsets (WebXR)** and on desktop browsers.
- 🌞 **Dynamic Lighting & Shadows** – Realistic sun simulation casting shadows on planets.
- 🎮 **Smooth Navigation & Controls** – Move freely using VR controllers or keyboard + mouse.

## 🚀 **Installation & Running Locally**
1️⃣ **Clone the repository**
```bash
 git clone https://github.com/vivekmishra5699/solar-vr.git
 cd solar-vr
```

2️⃣ **Install dependencies**
```bash
 npm install
```

3️⃣ **Start the development server**
```bash
 npm run dev
```

4️⃣ **Open in browser**
Navigate to [localhost:5173](http://localhost:5173/) to explore the Solar System! 🌍

## 🎮 **Controls**
### 🕶 **VR Mode** (Using Controllers)
- **Like Roller Coaster** – Ride along with Planets and look around 

### 🖥 **Desktop Mode** (Keyboard & Mouse)
- **Move**: `WASD` or Arrow Keys
